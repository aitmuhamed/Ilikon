01Систем ямар зарчмаар ажилладаг

Бүх зүйл нэг дүрмийн дор.

Гол дүрэм

Жороор олгох эмийг лицензтэй эм зүйч баталгаажуулаагүй бол хэзээ ч олгохгүй. Энэ нь зөвхөн текст биш — кодод хэрэгжсэн: жор шаардсан захиалга «Бэлтгэж байна» төлөвт хүрч чадахгүй.

Систем гурван хэсэгтэй:

  • Дэлгүүр — харилцагч эм хайж, захиалж, жор хуулна. Гурван хэлээр, анхдагч нь монгол.
  • Админ — ажилтны хяналтын самбар. Дүр тус бүр өөрийн эрхийн хүрээнд л хардаг.
  • AI зөвлөгөө — зовиурыг асуулгаар тодруулж, эрсдэлийг шалгаж, зөвхөн зохимжтой үед жоргүй бүтээгдэхүүн санал болгоно.

Захиалгын гинжин хэлхээ

Админ бүтээгдэхүүн үүсгэнэ → дэлгүүрт харагдана → харилцагч захиална → нөөц дэвтрээр хасагдана → админд захиалга гарна → төлбөр шинэчлэгдэнэ → жор шаардсан бол эм зүйч баталгаажуулна → хүргэлт хөдөлнө → харилцагч алхам бүрт мэдэгдэл авна.

04Дэлгүүр — харилцагчийн урсгал

Харилцагч юу хийж чадах вэ.

  • Хайх — нэр, брэнд, үйлчлэгч бодис, SKU, баркодоор. Категори, үнэ, нөөц, жортой/жоргүй, хямдрал, үнэлгээгээр шүүнэ.
  • Бүтээгдэхүүний хуудас — тун, анхааруулга, хажуугийн үйлдэл, хадгалалт, найрлага. Гурван хэлээр.
  • Сагс, төлбөр — нөөцийг сервер дээр шалгана. Гурван алхамт төлбөр.
  • Жор хуулах — /mn/prescriptions/upload. Зураг эсвэл PDF.
  • Хувийн хаяг — захиалгын түүх, дахин захиалах, хаяг, хүслийн жагсаалт, мэдэгдэл, AI зөвлөгөөний түүх.
Хэл

Анхдагч нь монгол. Хэрэглэгч хэлээ сонгох хүртэл хөтчийн хэлээс үл хамааран монголоор нээгдэнэ. Сонголт cookie-д хадгалагдана.

Зүүн доод талын цэсний товч дарж хажуугийн цэсийг нээнэ. Логон дарвал хяналтын самбар руу шилжинэ. Хүснэгтүүд хэвтээ гүйлгэнэ — хуудас өөрөө хажуу тийш гүйхгүй.

06Жор баталгаажуулах

Системийн хамгийн чухал ажил. Зөвхөн эм зүйч.

  1. Админ → Жор нээх. Дараалалд хүлээгдэж байгаа болон тодруулга хүссэн жорууд байна.
  2. Файлыг нээж уншина. Унших бүрт аудитад бичигдэнэ — хэн, хэзээ, хаанаас.
  3. Шийдвэр гаргана: Батлах · Татгалзах · Тодруулга хүсэх.
  4. Шалтгаан, тэмдэглэл бичнэ. Энэ нь харилцагчид мэдэгдэл болж очно.
Хэрэгжсэн хамгаалалт
  • Жор шаардсан захиалга баталгаажаагүй бол Бэлтгэж байна / Хүргэлтэнд / Хүлээн авсан төлөвт орохгүй.
  • Жор автоматаар батлагддаггүй — хянагчийг нэрлэсэн бичлэггүйгээр «Баталгаажсан» болох код байхгүй.
  • Файл нь нийтийн хаягаар хэзээ ч үйлчлэгддэггүй. Эрх шалгасны дараа л уншигдана, татгалзсан ч аудитад бичигдэнэ.
  • Хугацаа дууссан бараа зарагдахгүй — захиалгын гүйлгээ дотор дахин шалгагдана.

07AI зөвлөгөө — эм зүйчид

Триаж хэрэгсэл, эмч биш.

Харилцагч Иликон-той зөвлөлдөх нээж, тайлбарыг зөвшөөрч, зохицуулагдсан асуулгад хариулна. Систем 4 түвшинд эрсдэлийг үнэлж, зөвхөн зохимжтой үед эмийн сангийн өөрийн бүртгэлээс жоргүй бүтээгдэхүүн санал болгоно.

Эм зүйчийн хяналт

Админ → AI зөвлөгөө дээрээс бүртгэлийг нээнэ. Ямар асуулт асуусан, юу хариулсан, ямар эрсдэл илэрсэн, ямар бүтээгдэхүүн авч үзсэн (зөвхөн харуулсан биш), аюулгүй байдлын шалгалт бүрийн үр дүн, AI-ийн аудит лог — бүгд байна.

Дараа нь: Батлах · Зөвлөмж өөрчлөх · Татгалзах · Тэмдэглэл · Нэмэлт мэдээлэл хүсэх · Бүтээгдэхүүн санал болгох. Ангиллыг ч өөрчилж болно.

Эрэмбэ

Эм зүйч AI-г дийлнэ, AI эм зүйчийг хэзээ ч дийлэхгүй. Хянасны дараа систем дахин үнэлгээ хийхээс татгалзана, эм зүйчийн нэмсэн бүтээгдэхүүн бүх дахин үнэлгээнд хадгалагдана.

Систем хийдэггүй зүйл
  • Онош тавихгүй. Жороор олгох эм санал болгохгүй. Тун бичихгүй.
  • Харшил, жирэмсэн, нас, эмийн харилцан үйлчлэлийг үл хайхрахгүй.
  • Тодорхойгүй бол таамаглахгүй — эм зүйч рүү дамжуулна.
  • Яаралтай тохиолдолд бүтээгдэхүүн харуулахгүй.
Ашиглалтад гаргахаас өмнө

Мэдлэгийн сан (15 заавар, 33 хориглох дүрэм, 16 харилцан үйлчлэл) нь demo агуулга. Бодит харилцагчид хүрэхээс өмнө эмийн сангийн лицензтэй эм зүйч мөр бүрийг хянаж, дахин батлах ёстой.

DBeaver-т автоматаар нэмэх

DBeaver-ыг хаа, дараа нь:

powershell -ExecutionPolicy Bypass -File scripts\dbeaver-connect.ps1

Холболтыг data-sources.json-д нэмнэ (эхлээд нөөцөлнө). Нууц үгийг бичихгүй — DBeaver нэг удаа асууж, өөрийн шифрлэгдсэн санд хадгална.

Яагаад хаах шаардлагатай

DBeaver гарахдаа data-sources.json-г дахин бичдэг — нээлттэй байхад нэмсэн холболт дуугүй арчигдана. Скрипт үүнийг мэддэг тул нээлттэй байвал ажиллахаас татгалзана.

psql — тусад нь юу ч суулгахгүйгээр

docker exec -it ilikon-db psql -U ilikon -d ilikon

Prisma-ийн визуал хэрэгсэл: npm run prisma:studio

09Тохиргоо

Кодгүйгээр өөрчлөх зүйлс.

Админ → Тохиргоо: эмийн сангийн нэр, утас, хаяг, Google Maps, лицензийн дугаар, ажиллах цаг, хүргэлтийн хураамж, үнэгүй хүргэлтийн доод хэмжээ, төлбөрийн хэлбэрүүд, мэдэгдэл, SEO, нөөцийн сануулгын босго.

AI зөвлөгөөний тохиргоо

Админ → AI зөвлөгөө дотор. Хоёр эрхэд хуваагдана:

ТохиргооШаардах эрх

Санамсаргүй биш

Аюулгүй байдлын дүрмийг зөвхөн consultations.safety эрхтэй хүн өөрчилнө — анхдагчаар зөвхөн супер админ. Эрхгүй хүн өөрчлөхийг оролдвол API нь дуугүй хаяхгүй, ил татгалзана. Ерөнхий админд энэ эрхийг өгч болохгүй.

Яаралтай тусламжийн дугаар нь кодод бичигдээгүй — тохиргооноос уншигдана, тиймээс улс/хот өөрчлөгдвөл кодыг хөндөхгүй.

10Нууц үг, аюулгүй байдал

Интернэтэд гаргахаас өмнө.

Хамгийн эхэнд

Demo нууц үг нь нийтийн GitHub дээр байдаг. Аппыг интернэтэд гаргах бол хэн ч супер админаар нэвтэрч чадна. Нэн тэргүүнд солино уу.

# Ажилтны данснууд
npm run rotate:passwords

# Ажилтан + харилцагч
npm run rotate:passwords -- --customers

Данс тус бүрт хүчтэй санамсаргүй нууц үг үүсгэж, нэг л удаа харуулна. Хаана ч хадгалагдахгүй тул тэр дор нь password manager-т хийнэ үү. npm run db:seed дахин ажиллуулсан ч буцаахгүй.

Мөн заавал солих

  • AUTH_SECRET — openssl rand -base64 48
  • POSTGRES_PASSWORD (docker-compose.yml) ба түүнд тохирсон DATABASE_URL
  • NEXT_PUBLIC_SITE_URL — бодит хаяг

Системд хэрэгжсэн хамгаалалт

  • bcrypt (12 давталт) · httpOnly, гарын үсэгтэй JWT · CSRF, origin шалгалт
  • Бүх endpoint-д Zod шалгалт, урт хязгаартай
  • Файл байтаас нь танигдана, зарласан төрлөөс нь биш
  • Аудит лог — эрхтэй үйлдэл, жор унших бүрт
  • CSP, HSTS, X-Frame-Options, nosniff
  • Эрүүл мэндийн хариултыг эм зүйчээс бусад ажилтан харахгүй
Шалгасан, хүлээн зөвшөөрсөн

Хамаарлын сангуудад 6 өндөр эрсдэлт сануулга байгаа (sharp, postcss — Next.js-ээр дамжсан). Арилгахад next@16 том шинэчлэл хэрэгтэй, өөрийн регрессийн шалгалттай. npm audit-аар харна.

Quick Tunnel — данс, домэйн, төлбөргүй

NET=$(docker inspect ilikon-db --format '{{range $k,$v := .NetworkSettings.Networks}}{{$k}}{{end}}')

docker run -d --name ilikon-app-live --network "$NET" \
  -e DATABASE_URL="postgresql://ilikon:...@db:5432/ilikon?schema=public" \
  -e AUTH_SECRET="$(openssl rand -base64 48)" \
  -e STORAGE_DRIVER=local -e NODE_ENV=production \
  ilikon-pharmacy-app:latest

docker run -d --name ilikon-quick-tunnel --network "$NET" \
  cloudflare/cloudflared:latest tunnel --no-autoupdate \
  --url http://ilikon-app-live:3000

docker logs ilikon-quick-tunnel 2>&1 | grep trycloudflare.com

Зогсоох: docker rm -f ilikon-quick-tunnel ilikon-app-live

Нэртэй Tunnel — тогтвортой

Cloudflare самбар → Zero Trust → Networks → Tunnels → Cloudflared сонгож token хуулна. Дараа нь:

echo 'CLOUDFLARE_TUNNEL_TOKEN=eyJhIjoi...' >> .env
echo 'NEXT_PUBLIC_SITE_URL=https://ilikon.domain.mn' >> .env
docker compose --profile full --profile tunnel up -d --build

Tunnel-ийн Public Hostname табт: Service = HTTP, URL = app:3000.

Cloudflare самбарт
  • SSL/TLS → Full (strict)
  • WAF → Managed Ruleset нээх
  • Bots → Bot Fight Mode
  • Rate limiting → /api/auth/login-д минутад ~10
  • Caching → /api/*, /admin/* кэшлэхгүй. /api/consultations/* нь эрүүл мэндийн өгөгдөл — хэзээ ч кэшлэхгүй.
Порт 3000

Tunnel ашиглаж байгаа бол app сервисийн ports: блокийг авах нь илүү зөв — cloudflared дотоод сүлжээгээр очдог. Портыг гаргахгүй бол origin руу шууд хандаж WAF-ыг тойрох боломжгүй болно.

13Өгөгдөл хамгаалах

Эрүүл мэндийн өгөгдөл — хамгийн мэдрэмтгий.

AI зөвлөгөөний хариултууд нь эрүүл мэндийн өгөгдөл. Хадгалах хугацаа (анхдагч 365 хоног) дуусахад чөлөөт текст, хариулт, эмийн болон харшлын жагсаалт устгагдана; харин нэр холбогдоогүй үр дүн болон AI-ийн аудит лог хадгалагдана — эмийн сан системийн зан төлвийг хянаж, тайлагнаж чадахын тулд.

npm run consultations:purge

Хуваарьт (cron) тавина уу. Дахин ажиллуулахад аюулгүй — устгасныг purgedAt-аар тэмдэглэдэг.

Хэн харж чадах
  • Зөвлөгөөг эзэмшигч харилцагч
  • httpOnly cookie барьсан нэвтрээгүй хэрэглэгч
  • consultations.view эрхтэй ажилтан — унших бүрт аудитад бичигдэнэ

Бусад бүх тохиолдолд 404 — 403 биш, ингэснээр уншиж чадахгүй хүн зөвлөгөө байгаа эсэхийг ч батлаж чадахгүй.

14Асуудал шийдвэрлэх

Бодитоор тохиолдсон бэрхшээлүүд.

Build: EPERM ... query_engine-windows.dll.node

Ажиллаж байгаа сервер Prisma-ийн эрхийг барьж байна. Windows дээр pkill ажиллахгүй — PowerShell хэрэглэнэ.

Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -like '*ilikon-pharmacy*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

Could not find a production build

Build дундуур процесс тасалдаж .next бүрэн бус үлдсэн.

npm run build

ports are not available: ... :3000

Порт 3000-ыг өөр зүйл эзэлж байна (dev сервер эсвэл өөр төсөл). Эзэмшигчийг олж хаах, эсвэл tunnel ашиглаж байгаа бол ports: блокийг авах.

Get-NetTCPConnection -LocalPort 3000 -State Listen |
  ForEach-Object { Get-Process -Id $_.OwningProcess }

RATE LIMITED on /api/auth/login

Хамгаалалт зөв ажиллаж байна — IP тутам 5 минутад 8 оролдлого. Тестийг дараалан ажиллуулбал хүрнэ. 5 минут хүлээх, эсвэл серверийг дахин эхлүүлбэл хязгаар цэвэрлэгдэнэ (санах ойд байдаг).

DBeaver-т нэмсэн холболт алга болов

DBeaver нээлттэй байхад config бичсэн — гарахдаа дарж бичсэн. Хаагаад скриптийг дахин ажиллуул.

Терминалд кирилл үсэг эвдэрсэн харагдана

Windows PowerShell 5.1 нь BOM-гүй файлыг ANSI гэж уншдаг. Терминалын дэлгэц эвдэрсэн ч файл зөв байж болно — байтуудыг шалга. Өгөгдлийн санд кирилл бичихдээ shell-ээр биш, UTF-8 файлаар:

docker cp update.sql ilikon-db:/tmp/u.sql
MSYS_NO_PATHCONV=1 docker exec ilikon-db psql -U ilikon -d ilikon -f /tmp/u.sql

Ажилтны формыг хадгалахад бүдэг алдаа

Нууц үг дүрэмд нийцээгүй байх магадлалтай: 8+ тэмдэгт, үсэг ба тоо. Одоо формд тухайн талбар дээр нь шалтгаан харуулна.

Гар утсан дээр цэс дээд талд намхан цагаан хавтан болно

Зассан. Шалтгаан нь backdrop-filter бүхий элемент нь position: fixed удам садныхаа containing block болдогт байсан. Ийм зүйл дахин гарвал fixed элементийг бүдэгрүүлэлттэй элементийн гадна зөөнө.

Ерөнхий дараалал

npm run typecheck → npm run build → серверийг дахин эхлүүлэх → тест. Алдааны хамгийн түгээмэл шалтгаан нь хуучин процесс ажилласаар байгаа — хаясан гэж бодсон ч.
